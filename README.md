# Hub della Conoscenza

Una piccola biblioteca digitale di letture brevi su scienza, matematica, filosofia, cultura e storia.

## Pubblicazione su GitHub Pages

1. Crea un repository **pubblico** chiamato `hub-della-conoscenza`.
2. Carica nella radice del repository i file `index.html`, `.nojekyll` e `README.md` di questa cartella.
3. Su GitHub, apri **Settings → Pages**.
4. In **Build and deployment**, scegli **Deploy from a branch**, seleziona `main` e `/(root)`, poi salva.
5. Il sito sarà raggiungibile all'indirizzo `https://TUO-USERNAME.github.io/hub-della-conoscenza/` (sostituendo TUO-USERNAME).

## Modificare le letture

I testi sono contenuti nell'array `articles` nel file `index.html`. Puoi modificarli con un editor di testo o direttamente dall'editor web di GitHub; salva le modifiche con **Commit changes**.

Le letture sono sintesi originali e rimandano alle rispettive fonti; non sostituiscono la lettura delle pubblicazioni originali.
